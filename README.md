Objectives of Rock Paper Scissors Project

1. To develop a simple console-based game using C++.<br>
2. To understand the concept of conditional statements and loops.<br>
3. To implement random number generation for computer moves.<br>
4. To improve problem-solving and logical thinking skills.<br>
5. To practice functions, classes, and object-oriented programming concepts.<br>
6. To create an interactive and user-friendly game application.<br>


Features of Rock Paper Scissors Project<br>

1. User can choose Rock, Paper, or Scissors.<br>
2. Computer generates random choices automatically.<br>
3. Program compares player and computer choices.<br>
4. Displays winner or draw result instantly.<br>
5. Supports multiple rounds of gameplay.<br>
6. Simple menu-driven interface.<br>
7. Fast and easy-to-use console application.<br>
8. Uses basic C++ concepts suitable for beginners.<br>
